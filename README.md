# UFMT Ciência

Jogo educativo de exploração do campus Cuiabá da UFMT: registre animais e plantas de Mato Grosso, visite estações científicas e vença desafios nas arenas.

- Jogar: https://ufmtciencia.github.io
- Contas e ranking: Firebase (plano gratuito Spark), projeto ufmt-ciencia.
- Mapa: © colaboradores do OpenStreetMap (ODbL).
